## Promotion rule

A spoken candidate should not enter automatic bedtime recommendation just because it scores well here. It can enter the experimental study/drowsy library after a full-listening review confirms: no loud intro/outro, no sudden pitch jumps, no distressing content, no ads, stable technical playback, and verified commercial reuse rights. Automatic recommendation should require positive personal feedback.
